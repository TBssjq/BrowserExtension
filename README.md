# DeepSeek 对话批量选择助手

一个 Edge / Chrome 浏览器扩展（Manifest V3），为 `https://chat.deepseek.com/` 的**「选择对话」多选模式**加上一键批量勾选能力。

进入多选模式后，页面右下角会自动出现一个可拖拽的小面板，支持：

- **全选** —— 勾选列表里的全部对话（自动滚动整份列表，兼容虚拟滚动）
- **全不选** —— 取消全部勾选
- **反选** —— 已选的取消、未选的勾上
- **按日期选择** —— 复用站点自身的日期分组（今天 / 昨天 / 7 天内 / 30 天内 / 2025-07 …），勾选某个分组即可一次性选中该分组的全部对话

面板出现时会自动把整个列表扫一遍，因此**当前没有显示在屏幕上的旧对话，它们的日期分组同样会出现在面板里**。

## 安装

1. 打开 `edge://extensions/`（Chrome 为 `chrome://extensions/`）
2. 打开左下角/右上角的「开发人员模式」
3. 点击「加载解压缩的扩展」，选择本仓库根目录（包含 `manifest.json` 的目录）
4. 打开 https://chat.deepseek.com/ 并刷新一次页面

## 使用

1. 在 DeepSeek 侧边栏点击「选择对话」，进入多选模式
2. 右下角出现「对话批量选择」面板
   - 面板可拖动（按住标题栏），点 `–` 收起、点 `×` 隐藏
3. 点击「全选」或展开「按日期选择」勾选某个日期分组

> 面板只在检测到多选模式（列表中出现复选框）时自动出现，也可以在扩展弹窗里手动「显示面板」。

## 目录结构

```
manifest.json
src/
  core/dom.js        # 只读识别：复选框、对话行、日期分组推断
  core/actions.js    # 操作：模拟点击、滚动扫描、全选/反选/按分组选择
  ui/panel.js        # Shadow DOM 浮层面板
  main.js            # 入口：设置、MutationObserver、消息处理
  popup/             # 扩展弹窗
```

## 实现要点

- **不写死选择器**：站点结构变化频繁，扩展示例通过「复选框 → 向上找唯一对话行 → 向前找最近日期标题」的启发式规则定位元素。
- **样式隔离**：面板挂在 Shadow DOM 里，不受站点 CSS 影响，也不会污染站点样式。
- **兼容虚拟滚动**：批量操作前先把列表滚到顶部，逐屏勾选再滚回原位，因此翻页/懒加载的对话也能被选中。
- **点击模拟**：依次派发 `pointerdown / mousedown / pointerup / mouseup / click`，兼容只监听 `mousedown` 或 React 合成事件的实现。
- **状态兜底**：勾选状态优先读 `input.checked` / `aria-checked` / `data-state` / class；读不出来时用「本会话是否点过」推断，保证不会来回翻转。

## 常见问题

- **面板没出现**：确认已进入「选择对话」模式；若列表里只有 1 条对话不会自动显示，可在弹窗里点「显示面板」。
- **日期分组识别不到**：说明站点用了新的分组写法。在扩展弹窗的「自定义分组标题正则」里补一条规则即可，例如 `^(本周|上周|更早)$`，然后点面板上的「刷新」重新扫描。
- **分组数量对不上**：点一下面板里的「刷新」，它会重新完整扫描一遍列表（含未渲染的旧对话）。
